顺手完成三件高频小事

在 Mac 上，点击右上角的 AGS 图标可查看当前额度，悬停「切换账号」即可选择备用账号。

看余量，不盲猜

当前账号置顶，备用账号按套餐归组、按可用余量排好序，支持卡片与单行两种视图。Codex 分列 5h / 7d 与 Credits；Antigravity 以 Gemini 为主并独立展示 Claude / GPT 等模型组，缺失值如实显示「—」，不混算总比例。

添账号，不掉线

在浏览器中完成官方授权，可连续添加账号，当前客户端保持登录。多账号 JSON 可先预览、改名、按身份去重再导入。过期账号可原位更新并保留昵称，替换凭据前会核对身份。

留备份，不伤现场

选择账号并设置至少 6 个字符的密码，即可导出 .ags 加密备份，在另一台电脑上恢复。移除账号时可先核对范围，默认保留客户端登录、聊天历史和项目文件。

安全边界与支持范围

涉及账号凭据的工具先讲清楚边界：零自建服务器、源码公开可审，只动登录凭据，不碰聊天记录与项目配置。

本地安全保障

零自建后端，透明可审
登录仅放行 OpenAI 与 Google 官方授权域名。故障记录保存在本机，可在设置中导出脱敏报告并自行转交维护者。
本机凭据加密
账号凭据使用 AES-256-GCM 加密。macOS 钥匙串或 Windows 当前用户的 DPAPI 保护主密钥，导出的 .ags 备份使用独立密码。
不丢号、不越界
未入池的当前登录在切换前会弹窗提醒保护；只替换登录凭据，不动聊天历史与项目配置，也不会在后台偷偷自动切号。
使用边界明确
放入他人账号须事先获持有人授权；本版仅限本机使用，不含联网中转或多人共享服务。

下载与快速安装

Mac 版需要 macOS 13 或更高版本。可在「关于本机」查看芯片，后续在 AGS 设置中下载更新。Windows x64 用户可在此下载新版安装程序。

macOS 首次打开提示「无法验证开发者」？

Mac 安装包采用 ad-hoc 签名，尚未经 Apple 公证。核对下载来源后，可在「系统设置 → 隐私与安全性」中点击「仍要打开」。

macOS：将输出与同版 SHA256SUMS 对照 
shasum -a 256 AgentSwitcher-*.dmg

源码运行与 ags CLI

适合想直接审计源码、打包最新工作区，或在终端用 ags 命令快速切换的开发者（需 Node.js 22.12+）。

克隆并启动桌面窗口 
git clone https://github.com/xjzc-mt/agent-switcher.git
cd agent-switcher
npm ci && npm run build && npm run gui
常用 ags 命令（构建后 npm link 安装） 
ags save codex work   # 保存当前登录
ags list              # 查看已保存账号
ags status            # 查看当前激活状态
ags use codex work    # 切换至指定账号

门后的彩蛋

推开高门 · 解锁「终局形态」预言

今天朋友借号还得导凭据，深夜里大量订阅窗口又在倒计时中白白清零。而在终局形态里，每个人都可以是一座自主受控的「个人小中转」（并非公共商业号池或账号倒卖，而是熟人与小团队的私密互助工具）：

  • 借力免交凭据：账号空闲时，本机即可化作轻量微中转节点，搭档按需借力，无需交出密码或明文 JSON。
  • 信任圈私密默认，开关全权在己：默认仅对认可的熟人与小团队开放；谁能连、用多少、外部限制开关均由你本机实时掌控、随时撤回。
  • 闲置余量零浪费：队友赶工借你空闲窗口顶上，你冲刺时也有伙伴余量接力，让每一份订阅物尽其用。
