# 导航栏与小菜单设计

macOS 右上角小菜单随 1.0.1 发布，并已通过双屏验收。以下记录当前源码的常驻账号名单与左上角应用菜单。已发布版本的操作见 [1.0.1 更新说明](release-1.0.1.md)。

## macOS 菜单栏小菜单（当前源码）

点右上角 AGS 图标，从图标下方展开紧凑面板。主窗口和面板共用平台标志、品牌色、文字与额度颜色。展开时直接显示最近一次额度快照。

多屏使用时，小菜单留在本次点击的菜单栏图标下方。切换平台、滚动名单和刷新额度时保持位置。关闭后从另一块屏幕打开，面板跟随新点击的位置。

| 位置 | 显示与操作 |
| --- | --- |
| 顶部 | 标签切换 Codex 和 Antigravity。右上角刷新查询所选平台的当前登录与有效备用账号。名单逐项更新，收起面板后继续查询。 |
| 当前账号 | 昵称和套餐下方显示主额度、重置时间和进度条。Codex 按实际周期展示，Antigravity 展示 Gemini 主额度。旧快照标「上次记录」，逐个周期按查询状态和重置时间着色。缺值标「—」。凭据失效时可更新，未入池的本机登录可保存。 |
| 备用账号 | 「点选切换」下常驻显示可切换账号，沿用账号池排序。最多展示 8.5 行，超过后滚动名单。点击名称或额度发起切换。单周 Codex Pro 在 5h 列显示「不限」。没有备用账号时可「添加账号」，全部不可用时显示「暂无可切换账号」。 |
| 底部 | 左侧「打开主窗口」，右侧「退出」。 |

在平台标签上按左右方向键、Home 或 End 可切换平台。上下键选择备用账号，Enter 选择账号。支持查额时，打开面板会按该平台的自动刷新设置优先检查当前登录和前 4 个可切换候选。刷新保留已聚焦的账号与名单位置。昵称遮蔽完整邮箱。

Antigravity 2.x 仅装桌面版或本机 `agy` 需要更新时，小菜单显示账号和已知套餐，可直接点选切换。安装或更新官方 CLI 后，在主窗口点「重新检测」即可恢复两个窗口的额度功能。

需要退出客户端、保存当前登录、迁移长凭据或恢复中断切换时，面板在原屏列出目标与影响。Enter 执行主操作，Escape 返回名单。切换平台或点面板外会取消待确认的选择。名单上按 Escape 收起。更新凭据仍在主窗口办理。

## macOS 左上角系统应用菜单栏（源码版）

通过 `Menu.setApplicationMenu` 显式设置中文原生菜单，替换 Electron 默认英文调试菜单：

| 顶栏菜单 | 菜单项与快捷键 | 行为与约束 |
| --- | --- | --- |
| **AgentSwitcher** | `关于 AgentSwitcher` / `设置… (Cmd+,)` / 系统 `服务`、`隐藏 (Cmd+H)`、`隐藏其他 (Opt+Cmd+H)`、`全部显示` / `退出 AgentSwitcher (Cmd+Q)` | 原生 About 面板仅展示名称与当前版本，不加更新提示；`设置…` 聚焦主窗口并切到设置页；退出统一走 `quitGuard` |
| **账号** | `添加账号… (Cmd+N)` / `刷新全部额度 (Cmd+R)` / `重启当前客户端 (Shift+Cmd+R)` / `关闭窗口 (Cmd+W)` | 取代默认空置的 `File` 菜单。**将 `Cmd+R` 映射为业务层的「刷新全部额度」**，生产包彻底移除 `Reload / Force Reload`，防止重载网页清空弹窗草稿；`Cmd+W` 隐藏主窗口并保留渲染进程。有模态操作或待处理草稿时，窗口保留在原处 |
| **编辑** | `撤销 (Cmd+Z)` / `重做 (Shift+Cmd+Z)` / `剪切 (Cmd+X)` / `复制 (Cmd+C)` / `粘贴 (Cmd+V)` / `全选 (Cmd+A)` | 保留 macOS 原生 `Edit` 角色，确保搜索框、昵称输入、备份密码与 Session JSON 文本框的快捷键正常生效 |
| **视图** | `Codex (Cmd+1)` / `Antigravity (Cmd+2)` / `收起或展开侧边栏 (Opt+Cmd+S)` / `紧凑卡片视图`、`单行比较视图`（单选联动） | 与主窗口当前平台、侧栏折叠状态和 `accountLayout` 双向同步；仅在非打包开发态（`!app.isPackaged`）追加分隔线与 `开发者工具 (Opt+Cmd+I)` |
| **窗口** | `最小化 (Cmd+M)` / `缩放` / `打开主窗口 (Cmd+0)` / `前置全部窗口` | 可通过 `Cmd+0` 或点击菜单项恢复隐藏的主窗口 |
| **帮助** | `AgentSwitcher 项目主页` / `已知问题与反馈` | 外部浏览器打开固定 GitHub 仓库主页与 Issues 页，移除 Electron 默认外链 |

当页面存在打开的模态弹窗（`<dialog open>`）或 `quitGuard.isClosing()` 为真时，渲染层忽略 `Cmd+1/2`、`Cmd+,`、`Cmd+N`、`Cmd+R` 与视图切换指令，避免穿过遮罩改动底层页面状态。

## Windows 任务栏托盘（源码版）

主窗口默认隐藏原生菜单栏。任务栏通知区域使用彩色 AGS 图标。点击图标或从右键菜单选择「打开 AgentSwitcher」，已最小化的窗口会还原并获得焦点。右键菜单同时提供「退出」。这些行为已通过隔离模拟，浅色和深色任务栏的实机显示仍待验收。

## 主窗口导航栏与局部菜单边界（现状维护与微调）

1. **左侧导航栏（`#appSidebar` · 已实现）**：
   - 保持默认宽 `152px`（拖拽范围 `144–184px`）、折叠宽 `56px`（`36×36px` 图标按钮，悬停提示 `平台名 · N 个账号`）。
   - 顶部仅保留 `智能体` 分组与平台列表，右侧徽标仅统计已入池账号总数，不挂异常红点或剩余百分比；底部固定单一 `设置` 按钮（设置页内变为 `返回账号`），不在侧栏底部堆叠导入、导出、清理或 GitHub 入口。
2. **窗口顶栏（`.workspace-topbar` · 已实现）**：
   - 保持 `52px` 单一窗口拖拽区与左侧红绿灯避让间距（`#sidebarToggle` `left >= 88px`）。
   - 右侧仅保留主视图级动作 `刷新全部`（设置页隐藏），不在顶栏增加二级下拉菜单。
   - 首帧标题为「Codex 账号管理」，与当前平台的动态标题一致。
3. **局部小菜单克制原则（已实现，继续保持）**：
   - 备用池工具栏（搜索、卡片/单行切换、`管理`、`+ 添加账号`）保持平铺直达，不折叠进 `⋯` 更多下拉小菜单。
   - 右键点击当前账号或备用账号（或聚焦后按 `Enter` / `Shift+F10`）直接打开「账号详情」弹窗，不额外增加一层右键上下文小菜单（详见 [额度刷新](refresh-behavior.md)）。
