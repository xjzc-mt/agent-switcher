# 导航栏与小菜单设计

macOS 屏幕右上角的 AGS 小菜单已随 1.0.1 发布，已通过用户体验和双屏验收。左上角应用菜单仍在设计阶段。主窗口沿用已有侧栏和顶栏。

## macOS 菜单栏小菜单（已实现）

点右上角 AGS 图标，从图标下方展开紧凑面板。主窗口和面板共用平台标志、品牌色、文字与额度颜色。展开时直接显示最近一次额度快照。

多屏使用时，小菜单留在本次点击的菜单栏图标下方。切换平台、悬停展开账号和更新额度都沿用这次的位置。关闭后从另一块屏幕打开，面板跟随新点击的位置。

| 位置 | 显示与操作 |
| --- | --- |
| 顶部 | 在 Codex 和 Antigravity 之间切换，一次查看一个平台。 |
| 当前账号 | 显示昵称、已知套餐和主额度。Codex 按实际周期展示，Antigravity 展示 Gemini 主额度。缓存有标记，缺值显示「—」。凭据失效可直接进入更新流程，未保存的本机登录可直接保存。 |
| 切换账号 | 悬停后在原位展开全部可切换的备用账号，名单沿用账号池的排序，可以滚动。点击目标即切换。没有备用账号时显示「添加账号」，有备用账号但全都不可用时显示「暂无可切换账号」。 |
| 快捷操作 | 顶栏的刷新按钮只查询已开放平台的当前账号。「打开主窗口」和「退出」在切换行右侧，可直接点击。设置和账号管理在主窗口。 |

键盘聚焦「切换账号」后，按方向键展开并选择，按 Enter 切换。Escape 先收起名单，再按一次关闭面板。点面板外也可关闭。昵称遮蔽完整邮箱。普通切换直接更新面板里的当前账号。需要确认、更新凭据或处理草稿时，显示主窗口。关窗后仍可读快照、刷新和切换。

## 左上角系统应用菜单栏（Application Menu · 待实现方案）

通过 `Menu.setApplicationMenu` 显式设置中文原生菜单，替换 Electron 默认英文调试菜单：

| 顶栏菜单 | 菜单项与快捷键 | 行为与约束 |
| --- | --- | --- |
| **AgentSwitcher** | `关于 AgentSwitcher` / `设置… (Cmd+,)` / 系统 `服务`、`隐藏 (Cmd+H)`、`隐藏其他 (Opt+Cmd+H)`、`全部显示` / `退出 AgentSwitcher (Cmd+Q)` | 原生 About 面板仅展示名称与当前版本，不加更新提示；`设置…` 聚焦主窗口并切到设置页；退出统一走 `quitGuard` |
| **账号** | `添加账号… (Cmd+N)` / `刷新全部额度 (Cmd+R)` / `重启当前客户端 (Shift+Cmd+R)` / `关闭窗口 (Cmd+W)` | 取代默认空置的 `File` 菜单。**将 `Cmd+R` 映射为业务层的「刷新全部额度」**，生产包彻底移除 `Reload / Force Reload`，防止重载网页清空弹窗草稿；`Cmd+W` 仅关闭窗口，保留托盘与 Dock 常驻 |
| **编辑** | `撤销 (Cmd+Z)` / `重做 (Shift+Cmd+Z)` / `剪切 (Cmd+X)` / `复制 (Cmd+C)` / `粘贴 (Cmd+V)` / `全选 (Cmd+A)` | 保留 macOS 原生 `Edit` 角色，确保搜索框、昵称输入、备份密码与 Session JSON 文本框的快捷键正常生效 |
| **视图** | `Codex (Cmd+1)` / `Antigravity (Cmd+2)` / `Claude Code（开发中）`（禁用） / `收起或展开侧边栏 (Opt+Cmd+S)` / `紧凑卡片视图`、`单行比较视图`（单选联动） | 与主窗口当前平台、侧栏折叠状态和 `accountLayout` 双向同步；仅在非打包开发态（`!app.isPackaged`）追加分隔线与 `开发者工具 (Opt+Cmd+I)` |
| **窗口** | `最小化 (Cmd+M)` / `缩放` / `打开主窗口 (Cmd+0)` / `前置全部窗口` | 主窗口已关闭时可通过 `Cmd+0` 或点击菜单项重新创建窗口 |
| **帮助** | `AgentSwitcher 项目主页` / `已知问题与反馈` | 外部浏览器打开固定 GitHub 仓库主页与 Issues 页，移除 Electron 默认外链 |

当页面存在打开的模态弹窗（`<dialog open>`）或 `quitGuard.isClosing()` 为真时，渲染层忽略 `Cmd+1/2`、`Cmd+,`、`Cmd+N`、`Cmd+R` 与视图切换指令，避免穿过遮罩改动底层页面状态。

## 主窗口导航栏与局部菜单边界（现状维护与微调）

1. **左侧导航栏（`#appSidebar` · 已实现）**：
   - 保持默认宽 `152px`（拖拽范围 `144–184px`）、折叠宽 `56px`（`36×36px` 图标按钮，悬停提示 `平台名 · N 个账号`）。
   - 顶部仅保留 `智能体` 分组与平台列表，右侧徽标仅统计已入池账号总数，不挂异常红点或剩余百分比；底部固定单一 `设置` 按钮（设置页内变为 `返回账号`），不在侧栏底部堆叠导入、导出、清理或 GitHub 入口。
2. **窗口顶栏（`.workspace-topbar` · 已实现，待对齐首帧文案）**：
   - 保持 `52px` 单一窗口拖拽区与左侧红绿灯避让间距（`#sidebarToggle` `left >= 88px`）。
   - 右侧仅保留主视图级动作 `刷新全部`（设置页隐藏），不在顶栏增加二级下拉菜单。
   - **微小修正项**：将 `renderer/index.html` 中 `#viewTitle` 的静态初始文本由 `Codex 调度中心` 改为 `Codex 账号管理`，与 `renderer/app.js` `selectTab()` 的动态标题完全一致，消除启动瞬间的文字跳变。
3. **局部小菜单克制原则（已实现，继续保持）**：
   - 备用池工具栏（搜索、卡片/单行切换、`管理`、`+ 添加账号`）保持平铺直达，不折叠进 `⋯` 更多下拉小菜单。
   - 右键点击当前账号或备用账号（或聚焦后按 `Enter` / `Shift+F10`）直接打开「账号详情」弹窗，不额外增加一层右键上下文小菜单（详见 [额度刷新](refresh-behavior.md)）。
