# AgentSwitcher v1.0.0 · 账号与额度，一处管理

> 本文保留初始 1.0.0 源码与测试包的历史说明。下文安装步骤以该版本公开提供附件为前提。当前的功能、平台范围及旧备份兼容性见 [1.0.1 候选版说明](release-1.0.1.md)。

AgentSwitcher（AGS）是本地 AI 编程工具账号与额度管理器。把自己的常用账号、同事或朋友授权使用的备用账号保存起来，先看剩余额度，再选择要用的账号，让切换、补充账号和备份都更顺手。

首版提供 **macOS Apple Silicon 桌面应用**与源码安装的 `ags` CLI，重点支持 **Codex 和 Antigravity**。

## 首版能做什么

- **看清可用额度**：当前账号与备用账号一屏查看，按套餐分组；卡片和单行视图可切换，支持搜索、排序、折叠与手动刷新。
- **保存和切换账号**：保留账号昵称，切换前同步凭据；运行中的桌面客户端在确认后正常退出，再尝试重开。
- **添加账号更方便**：独立官方浏览器登录，支持无痕入口和连续添加；添加备用账号不切换当前客户端登录。
- **批量导入与原位更新**：完整客户端凭据 JSON 可预览、命名和选择导入；失效账号核对身份后更新，保留原名称。
- **本地加密与密码备份**：账号池凭据使用 AES-256-GCM，macOS 密钥由 Keychain 保管；导出 `.ags` 使用独立密码加密，支持跨机器恢复。
- **清楚掌握操作范围**：移除前展示账号及同身份备份范围，默认保留客户端登录；设置页提供偏好、清理指令复制和下载安装包入口。

界面与操作截图见 [README](../README.md)，包含自己、同事、朋友和小组协作场景。截图使用演示账号和模拟额度。

## 安装

1. 从 v1.0.0 的 Assets 下载 `AgentSwitcher-1.0.0-arm64.dmg` 和 `SHA256SUMS`，放在同一目录。
2. 在该目录运行 `shasum -a 256 -c SHA256SUMS`，确认显示 `OK`。
3. 退出旧版 AgentSwitcher，打开 DMG，把 `AgentSwitcher.app` 拖入「应用程序」，再启动应用。
4. 选择平台，点击「添加账号」，保存本机登录、独立登录或导入已有凭据。

当前打包配置使用 **ad-hoc 签名，尚无 Developer ID 签名与 Apple 公证**。macOS 可能提示无法验证开发者；确认来源和校验值后，按系统「隐私与安全性」提示批准打开。SHA-256 校验不等于 Apple 认证。

首版仅面向 Apple Silicon Mac；Intel Mac、Windows 与 Linux 暂不提供安装包。DMG 不安装终端命令；CLI 安装方法见 README。

## 平台与使用边界

| 平台 | 首版支持 | 使用条件 |
| --- | --- | --- |
| Codex | 文件凭据保存和切换、独立登录、当前与备用账号订阅额度 | 需要本机 Codex 客户端；Keychain-only 登录未适配，API Key 不显示订阅额度 |
| Antigravity | macOS 2.x 个人 Google 账号切换、独立登录、套餐与模型组额度 | 独立授权和额度需要官方 `agy` CLI；企业认证与其他系统的新认证未验证 |
| Claude Code | 暂不开放 GUI 入口 | 保留已有数据与适配代码，后续完善 |

切换前请完成或停止正在进行的任务。已有终端会话需要自行重启；切换只处理登录凭据，不迁移项目、聊天记录或模型/MCP 配置。当前版本不会按额度自动切换账号。

额度以平台实际返回为准，查询失败会保留历史记录；“已切换”表示本地凭据写入检查通过。服务端撤销凭据时，仍需重新登录。完整行为见[账号管理流程](account-management.md)。

## 已有用户与回退

应用标识和数据路径为 `com.agent-switcher.app`、`~/.agent-switcher/`。旧明文账号池会逐文件验证并迁移为密文。跨机器迁移时，两端使用兼容的 AGS 版本。初始 v1.0.0 导出的加密备份为 AGS1；后续修复构建可以导入 AGS1，导出的格式为 AGS2。若计划回退到初始版本，请在升级前用初始版本导出并保留 AGS1 备份。
