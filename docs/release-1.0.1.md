# AgentSwitcher 1.0.1 候选版

2026-11-20。Apple Silicon Mac 的 1.0.1 候选安装包已在本地构建并校验，主要管理 Codex 和 Antigravity。公开下载以 GitHub Releases 上实际提供的附件为准。[发布记录](https://github.com/xjzc-mt/agent-switcher/releases)

## 从 1.0.0 测试版升级后有什么变化

- **Antigravity 保存与切换。** 支持个人账号使用的桌面与 CLI 认证文件。两端属于同一登录时，AGS 优先保存仍可用的凭据。需要把长凭据迁移到官方文件时，会先说明并请求确认。检测到两端分别登录或文件格式无法识别时，会保留原登录。[问题记录](../issues/AGS-0001-antigravity-file-auth.md)
- **使用中查看额度。** 官方客户端正在使用当前登录时，AGS 会优先用同一登录的有效访问令牌只读查询。暂时取不到新额度时，详情显示等待原因和上次成功时间。连续点击会复用进行中的检查。[额度刷新](refresh-behavior.md)
- **macOS 菜单栏。** 点击右上角 AGS 图标可查看当前额度，悬停「切换账号」即可选备用账号。在两块屏幕上使用时，切换平台或展开名单会留在打开菜单的那块屏幕。[菜单说明](navigation-menus.md)
- **账号与备份。** 单个损坏账号可以单独处理。新账号名会检查跨平台兼容性，旧版 macOS 账号仍可更新凭据或改名。导出备份时可设置 6 个字符或更长的密码。导入旧备份时，可在预览中修正不兼容的名称。[账号管理](account-management.md)
- **故障反馈。** 在「设置 → 应用与更新 → 导出故障报告」可保存近期操作经过、查询结果和构建标识。账号以报告内编号显示，用户可选择私下转交维护者。
- **更新校验。** 应用内下载先验证发布者签名，再检查安装包的大小和 SHA-256。安装仍由用户打开 DMG 完成。[应用内更新](app-updates.md)

## 升级与回退

如果正在使用初始 1.0.0 测试包，请先用旧版导出并保留一份加密备份及其密码。1.0.1 可读取旧版 AGS1 备份，新导出使用 AGS2；回退到初始版本时应恢复升级前的 AGS1。应用标识和账号池目录沿用原位置。桌面安装包和从源码安装的 `ags` 命令分别更新。
