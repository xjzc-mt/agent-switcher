# 应用内下载更新

## 范围

「设置 → 应用与更新」显示版本、更新说明和可用操作，并提供自动检查、导出故障报告和 GitHub 入口。macOS 和 Windows x64 版可直接下载并校验各自的安装包。当前源码在安装包就绪后提供「立即安装并重启」。macOS 从源码、只读卷或不可写位置运行时，按钮显示「打开安装并退出」。

更新器匿名访问固定的 `xjzc-mt/agent-switcher` GitHub Releases。接口返回 404 时，设置页显示暂未取得可用版本。正式分发需要用户能匿名读取发布记录、安装包和签名清单。如改用专用发布仓库，应同时更新应用、官网和 README 的入口，并为旧用户提供首次手动升级方式。

## 行为

- 打包运行时默认每 24 小时至多自动检查一次，手动检查遵守服务端限流；开发运行仅手动检查。可取消勾选自动检查，不再提供忽略版本；旧缓存中的忽略记录不影响新版展示，检查失败不能显示已是最新。
- 新版号旁的「更新说明」以纯文本显示最近一次成功检查时取得的 GitHub Release 正文。说明默认收起，展开只读取缓存。发布者修改正文后，已安装的 AGS 会在下次成功检查新版时取到新文案。下载完成后显示对应的安装操作。
- 稳定版本按版本号比较（已退役的早期测试版 `1.0.0`、`1.0.1` 不视为新版，避免回调至 `0.1.x` 后误回跳）。macOS 按运行架构选择 Apple Silicon 或 Intel 的 DMG，Windows x64 版选择 x64 的 EXE。缺少对应安装包、附件有歧义或没有校验信息时，可通过 GitHub 按钮前往项目主页查找发布版本。
- 一次下载固定版本、资产与校验值。使用 Electron 下载能力，独立于窗口生命周期；文件写入系统下载目录内的 AgentSwitcher 专属临时目录。系统未配置下载目录时，使用应用数据目录下的 `downloads` 子目录。
- 应用用内置 Ed25519 公钥验证安装包同名的 `.signed.json` 清单。签名绑定项目、版本、文件名、大小和 SHA-256。GitHub 同时提供 digest 时也要一致。签名缺失或不匹配时，只显示发布信息与项目页。
- 下载进度、取消和失败显示在设置内。服务器声明的长度与签名清单不符时取消接收；长度未知时，收到的字节一旦超限就取消并清理临时文件。下载完成时核对大小与哈希。点击安装时重新验证签名清单，并核对私有暂存副本的 SHA-256。重启会重新验签缓存，旧版只保存哈希的下载记录需要重新检查签名。真正退出时取消未完成下载，只关闭主窗口时下载继续。
- GitHub 网络失败时，网页下载入口也可能无法访问；当前不使用第三方代理或镜像。
- 发布清单签名用于验证 AGS 发布者。macOS 的公证和下载来源提示、Windows 的安装程序信誉提示均由操作系统处理。

## 退出与安装

点击安装后，AGS 将已下载的制品复制到独立的私有暂存目录，只交接通过校验的副本。macOS 目录权限为 `0700`，Windows 通过受保护的 ACL 仅授权当前用户。下载文件变动而导致校验失败时，设置页提供重新下载。

安装与 Cmd+Q 共用退出流程。AGS 等待已开始的账号写入及续期回存，有未保存的登录、导入草稿或未完成的下载时仍请求确认。选择「继续使用」会撤销本次安装并清理暂存。确认退出且写入已结束后，才交接给系统安装流程。

- **macOS 可写安装位置**。AGS 先只读挂载已校验的 DMG，确认存在 AgentSwitcher.app。旧进程退出后，辅助进程将新应用复制到目标同一卷，原子交换两个应用包，再打开新版本。如果打开命令失败，尝试换回并重开原包。已确认缺少应用的 DMG 停止使用，用户可再次检查修正后的发布制品。
- **macOS 手动安装**。AGS 打开已校验的暂存 DMG 并退出。将应用拖入「应用程序」并重新打开即可。此时系统仍需使用镜像，私有副本留在系统临时目录。
- **Windows x64**。辅助进程等待旧 AGS 退出，从私有目录静默运行 NSIS，由安装器启动新版。辅助进程只等待安装器本身退出，启动失败或退出码非零时才尝试重开原程序。随后清理暂存目录，遇到短暂占用时最多重试三次。

安装器更新 AGS 应用文件，沿用现有账号池与系统凭据，Codex 和 Antigravity 保持运行。重新启动后以实际应用版本为准。单独从源码安装的 `ags` CLI 需要单独更新。

## 发布流程

从同一提交构建两款 DMG 和 Windows 安装程序，为三个安装包分别生成签名清单，并生成一份供手动核对或旧版客户端使用的 `SHA256SUMS`。将文件上传至版本草稿，核对后发布。更新说明和后续修复的版本规则见[构建与发布](releasing.md)。

首次安装可通过官网托管的 `install.sh`（macOS）或 `install.ps1`（Windows x64）拉取最新正式版并核对 `.signed.json` 清单的大小与 SHA-256，安装至当前用户可写的标准目录以衔接后续应用内一键更新；也可直接从可信渠道手动下载安装包。旧版 `1.0.x` 切至 `0.1.x` 需运行一键脚本或手动覆盖安装一次，此后按 `0.1.x` 在应用内升级。使用新版检查历史无签名 Release 时仍可访问项目页。

## 验证边界

业务与界面测试用模拟数据覆盖三种安装包的版本选择、签名校验、下载、安装交接和缓存恢复，并覆盖损坏下载、取消及退出保护。实装 1.0.0 的更新模块已在隔离目录匿名发现 1.0.1，并验证 Apple Silicon 安装包的签名清单。三个公开安装包均已下载并核对 SHA-256。本机隔离测试使用真实测试 DMG 验证取消、替换和打开失败后的回滚。Windows NSIS 实装及升级后的正式账号池仍待实机验收。[发布核验记录](当前待办.md)
