## P1 · 故障现场记录与报送

1.0.1 可在「设置 → 应用与更新 → 导出故障报告」保存本地 JSON。近期操作按触发方式、步骤、时间和结果记录。异常及邻近操作优先保留，连续相同等待合并。进程意外结束时，下次启动可识别此前未完成的操作。账号以报告内编号显示。详情见[账号管理流程](account-management.md)。

待做的是一键私下送达维护者。需要确定私有接收端、维护者访问权限、保存期限及删除方式，然后更新隐私说明。当前由用户自行决定是否转交导出的文件。
