# AGS-0002 · 小菜单切换平台时从副屏跳到主屏

- 状态：已关闭，1.0.1 候选源码已通过用户双屏体验验收。
- 影响范围：macOS 菜单栏小菜单，多显示器。

## 1. 现象与复现

从副屏菜单栏打开 AGS，切换 Codex 和 Antigravity。两页内容高度不同时，旧版可能把菜单移到主屏，后续还需把鼠标移到另一块屏幕才能继续操作。

## 2. 根因与修复方案

旧版在每次内容高度变化时重新读取系统托盘图标坐标。系统返回另一块屏幕的图标位置后，AGS 用它重设了整个窗口的位置。修复后，点击图标时记录该次打开的位置和屏幕工作区，切换平台、刷新和展开名单时沿用该位置。[窗口实现](../../src/tray-menu.ts)

## 3. 修复记录

2026-11-20，加入一个回归用例，覆盖打开后的图标坐标变化、关闭后从另一屏重开，以及打开时系统返回旧屏图标位置。上一轮业务源码 +21/−6，测试 +64 行，菜单文档 +2 行，脚本无变动。[回归用例](../../tests/tray-position.test.cjs)

## 4. 验收记录

在两块真实显示器上，使用模拟托盘点击、模拟账号和真实 Electron 窗口。旧版切页后窗口纵坐标从副屏的 −1406 跳到主屏的 37。新版在副屏切页及展开、收起名单时保持原位，从主屏重新打开则跟随主屏。极短间隔连续注入点击不能替代人工鼠标体验；本轮候选复跑了自动化回归。

2026-11-20，用户在 1.0.1 候选源码体验后确认“双屏通过”。本问题关闭。
