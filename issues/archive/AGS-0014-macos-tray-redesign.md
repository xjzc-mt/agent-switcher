# AGS-0014 · macOS 菜单栏小菜单重设计：常驻展开、额度优先与定宽双列语义胶囊

- 状态：已关闭
- 发现日期：2026-11-24
- 平台：macOS（菜单栏托盘面板 `tray`）
- 来源：本地用户视觉与交互评审定稿

## 1. 现象与复现

打开 macOS 右上角 AGS 菜单栏小菜单（宽 `260px`），存在四处体验与视觉问题：
1. **备用账号额度列错位**：[renderer/tray.js](../../renderer/tray.js) 第 `41` 行将 `5h 100% · 7d 87%` 拼成单字符串右对齐，当末尾百分比在 3 位数（`100%`）、2 位数（`87%`）与 1 位数（`0%`）之间变化时，整串文字左右漂移，无法形成垂直列对齐。
2. **额度无语义颜色警示**：当前账号仅剩 `7d 9%`、备用账号 `7d 0%` 时仍为普通深灰/黑字，无法像主窗口一样一眼分辨充足、常规、偏低与耗尽。
3. **主账号主次层级颠倒**：当前使用账号将昵称设为 `15px` 粗体视觉重心，而用户最关心的剩余额度仅以 `11px` 弱化小字附在下方。
4. **悬停展开步骤多余且易抖动**：用户点开小菜单的核心目的就是看当前额度和直接点选备用号切换；现有悬停「切换账号 ⌄」才展开、移向右侧「打开主窗口 / 退出」又自动收起的设计既增加操作步骤，又导致面板高度频繁跳动。

## 2. 根因与修复方案

### 根因定位
1. [renderer/tray.html](../../renderer/tray.html)、[renderer/tray.css](../../renderer/tray.css) 与 [renderer/tray.js](../../renderer/tray.js) 沿用了早期「折叠抽屉 + 纯文本拼接」的极简雏形，未复用主窗口 [renderer/theme.css](../../renderer/theme.css) 的语义状态色与等宽列网格设计。
2. [src/tray-menu.ts](../../src/tray-menu.ts) 与 [renderer/app.js](../../renderer/app.js) `trayAccount()` 仅向小菜单传递了窗口标签和剩余百分比，缺少主账号重置时间文本、单周期/无短窗口限制（如 Codex `Pro`）等结构化展示字段。

### 修复方案（按已确认的「方案 A · 款式 3 定稿」实施）

1. **整体结构改为「顶栏 + 额度优先主账号区 + 常驻展开备用列表 + 独立底栏」（宽 `260px`）**：
   - **顶栏**：保留左侧 `Codex / Antigravity` 分段切换与右侧刷新图标按钮。
   - **彻底移除悬停折叠机制与相关死代码**：删除 `#switch` 折叠触发按钮、箭头图标、`expand()`、`leaveTimer`、`onpointerenter / onpointerleave / onfocusout` 收起逻辑；**严禁保留无调用的折叠残留代码或废弃样式**。
   - **底部独立操作栏（高约 `30px`）**：上方细边线分隔，左右平稳放置 `打开主窗口` 与 `退出` 两个低频按钮，不再与切换区耦合。

2. **当前使用账号区（Hero 区）：反转为「额度大字主角 + 紧凑身份眉标」且锁高防跳动**：
   - **第一行紧凑身份眉标**：左侧绿色在用圆点（`6px`）+ 账号昵称（`11.5px~12px` 次级字重，超长省略，保留完整邮箱遮蔽规则）+ 套餐小铭牌（如 `PRO`、`Plus`、`Ultra 20×`）；若为缓存数据（`cached || windowClosed`），右侧弱化标注 `上次记录`。
   - **第二行核心额度展示（正常有额度态固定区域高度约 `66px`，确保在单周期与双周期平台/账号间切换时面板外框零跳动）**：
     - **单周期**（如 Codex `Pro`）：横排展示周期名（`7d 剩余`）+ **`17px` 粗体语义状态色百分比** + 右侧重置时间（复用主窗口 `resetFormat` 倒计时/日期格式，如 `↻ 1天14时`）+ 下方 `4px` 圆角进度条（填充色随充足/常规/偏低/耗尽/缓存语义变化）；
     - **双周期**（如 Codex `Plus`、Antigravity `Gemini`）：左右 `1fr | 1fr` 对称双栏（中间 `1px` 细分隔线），每栏显示周期名 + **`17px` 粗体语义色百分比** + 简短重置时间 + 下方 `4px` 进度条；
     - **特殊状态**：未登录显示 `尚未登录`（或 `unavailable` 说明），未入池本机登录显示 `保存当前登录` 按钮，当前账号凭据失效显示身份眉标与 `更新凭据` 按钮，平台不支持额度或暂无数据时紧凑提示。

3. **备用账号列表：默认常驻展开 + `5.5 行` 限高滚动视口**：
   - 有可切换备用账号（`alternates.length > 0`）时默认直接渲染列表：
     - **单行列头（高约 `24px`）**：左侧显示 `点选切换 (N)`，右侧与下方数据列严格共享同一 Grid 列宽展示周期列头（标准双周期为 `5h` | `7d`；若某平台无额度能力则隐藏右侧列头）；
     - **限高防超长（20+ 账号场景）**：列表滚动容器固定 `max-height: 154px`（单行高 `27px` 时恰好露出 **5.5 行**，第 6 行露半截自然提示可上下滚动），确保即便有 20~50 个账号，整个小菜单总高度也恒定在 **`~312px` 以内**；账号少于 6 个时按实际内容高度自然贴合。
   - 无可切换备用账号（`alternates.length === 0`）时隐藏列头与空列表：若 `total === 0` 显示可点击的 `添加账号` 入口；若 `total > 0`（全部失效不可切）显示静音提示 `暂无可切换账号`。

4. **备用账号行：定宽等大语义胶囊 + 款式 3 消除「PRO=5h」错觉**：
   - **严格等宽网格与等大胶囊**：备用行采用 CSS Grid `minmax(0, 1fr) 44px 44px`（`gap: 5px`，`tabular-nums`）；所有真实百分比胶囊严格固定尺寸 **`44px × 19px`**、`4px` 圆角、居中对齐，复用 [renderer/theme.css](../../renderer/theme.css) 同款色值（充足 `>=80%` `--quota-ample-bg/text`、常规 `31~79%` `--quota-normal-bg/text`、偏低 `1~30%` `--quota-low-bg/text`、耗尽 `0%` `--quota-empty-bg/text`、缓存 `--quota-cached-bg/text`），使 `100%`、`87%`、`9%`、`0%` 像素级等宽等高。
   - **单周期 `Pro` 与双周期混排规则（严防 `PRO = 5h` 错觉）**：
     - **身份归左列**：单周期 `Pro` 账号在左侧名称旁展示轻量中性细框小标 `PRO`（**严禁将 `PRO` 文字放进右侧 `5h` 额度列下**）；
     - **`5h` 列使用款式 3 透明底细虚线槽（`44px × 18px`，`1px dashed`）**：对原本无短窗口限制的单周额度套餐（如 Codex `Pro`），`5h` 列虚线槽显示 **`不限`**（顺着列头 `5h` 往下读即为「`5h`：不限」，悬停 `title` 补充说明无 5h 窗口限制），`7d` 列显示实心语义百分比胶囊；若列表内 `Pro` 组下方紧接 `Plus` 等其他套餐行，在交界处渲染一条 `1px` 极浅分隔线；
     - **缺失值区分**：对于应有某周期但本次未取得数值（`remaining === undefined`）的槽位，显示 **`—`**，绝不伪造百分比，也不误标为 `不限`。
   - **特殊多/异周期兼容**：若某平台/账号返回非标准周期名称且无法与表头 `5h / 7d` 对应时，按实际窗口在槽位内紧凑展示或回退文本，保证不丢数据、不溢出 `260px` 面板。

5. **键盘操作与无障碍更新**：
   - `ArrowLeft / ArrowRight / Home / End` 切换顶部平台标签；
   - 面板内按 `ArrowDown / ArrowUp` 可直接在常驻备用账号行之间移动焦点并保持滚入视口，刷新推送时保持当前焦点与 `scrollTop` 不丢失；
   - `Escape` 直接关闭小菜单面板。

### 边界约束（不做什么）
- 不改变小菜单的多显示器定位与防跳屏逻辑（[src/tray-menu.ts](../../src/tray-menu.ts) 既有坐标锚定保持不变）。
- 不在小菜单内增加搜索框、分组折叠开关、右键菜单或设置入口，保持极简点选即切体验。
